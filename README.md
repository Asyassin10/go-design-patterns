# Go Design Patterns

> A small workshop for exploring creational patterns in Go.

This repo is a collection of compact examples. Each one focuses on a different way to create and organize objects, using familiar scenarios such as vehicles, payments, and shirts.

## Take a look around

| Pattern | In this project |
| --- | --- |
| **Singleton** | Reuse one shared instance across repeated calls. |
| **Builder** | Put together cars, bikes, and buses in a series of steps. |
| **Factory** | Choose a payment method or vehicle implementation from a requested type. |
| **Prototype** | Copy a shirt template and customize the copy. |

## Where things live

- `main.go` — the examples gathered in one place
- `creational/` — the pattern types and implementations

The examples are intentionally small, so the pattern itself stays easy to spot. They’re a starting point for reading and experimenting, rather than a full application.
